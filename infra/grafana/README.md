# Respondr Grafana Dashboards

Dashboard JSON files will be added in Phase 7 (Observability).

Planned dashboards:
- `respondr-overview.json`     — system-wide health (throughput, error rate, latency)
- `incident-analytics.json`   — MTTA/MTTR trends, incident volume by team/service
- `alert-pipeline.json`       — webhook ingestion rate, dedup ratio, alert-to-incident lag
- `jvm-metrics.json`          — heap, GC, thread pool metrics
